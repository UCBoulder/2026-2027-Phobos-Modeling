Welcome to the Phobos git repository!
This is a place where you can put your models and/or codes so they can be easily accessed by the entire team.
How you want to handle organization within your individual folders is up to your team.
DO NOT edit other team's files unless you are given explicit permission.
If you are worried about conflicts and overwriting files, you can always change the file name so the original is not removed.
Revert undoes the push that you are clicking on. It does not revert back to the state that the files were in at the time of the push.
You can alternatively create branches; this will create an "alternate universe" where changes made to the main branch will not be added to the new branch. Please only do this to avoid conflict and then remerge to the main branch.
Branches are useful for seeing how the files were in the past.
If you have any questions, please feel free to reach out.
